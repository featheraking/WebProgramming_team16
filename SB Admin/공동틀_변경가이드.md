# 공통 틀(상단바·사이드바) 변경 가이드

**각자 본문(`container-fluid` 안쪽)과 본인 CSS·JS는 그대로** -> 틀 부분만 수정

## 바뀐 부분

- 상단바: 흰 배경 + 검색창 + 알림 + **[로그인 / 회원가입]** 버튼 (로그인하면 `OOO님 환영합니다` + 로그아웃)
- 사이드바: 남색 배경, 메뉴 아이콘, **지금 보고 있는 페이지 자동 파란색 표시**, 폭 225px → 260px
- 메뉴구성: 홈 / 시험 벼락치기 스케줄러 / 팀 프로젝트 워크스페이스 / URL 스캐너 / AI 톤 체인저 / 설정 / 로그아웃
- 글꼴: Pretendard


---

## A. 새로 페이지를 만드는 경우

`template.html` 복사해서 '<title>'이랑 '<!--본문작업-->' 부분만 작업하시면 됩니다! (사이드바, 푸터 사이)

CSS는 `<head>`의 `<!-- CSS 추가 -->` 자리
JS는 `</body>` 바로 위 `<!-- JS 추가 -->` 자리


## B. 이미 기존 템플릿을 복사해서 작업 중인 경우

본문은 건드리지 않고 아래 4군데만 바꾸면 됩니다.

### 1. `<head>` — `styles.css` 바로 아래에 2줄 추가

```html
<link href="css/styles.css" rel="stylesheet" />
<!-- ↓ 추가 -->
<link href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css" rel="stylesheet" />
<link href="css/frame.css" rel="stylesheet" />
```

### 2. `<body>` — 클래스 추가

```html
<body class="sb-nav-fixed sch-frame">
```

### 3. 상단바·사이드바 통째로 교체

내 파일에서 **`<nav class="sb-topnav ...">`부터 `<div id="layoutSidenav_content">`까지**를 지우고,
`template.html`의 같은 구간(`<!-- ===== 공통 틀: 상단바` ~ `<div id="layoutSidenav_content">`)을 붙여넣습니다.

### 4. 푸터 ~ 공통 스크립트 교체

내 파일에서 **`<footer ...>`부터 `<script src="js/scripts.js"></script>`까지**를 지우고,
`template.html`의 같은 구간(`<!-- ===== 공통 틀: 푸터` ~ `<script src="js/frame.js"></script>`)을 붙여넣습니다.

> 그 아래에 있던 **내 JS `<script>`와 내 `<dialog>` 등은 그대로** 두세요.

## 참고: 로그인 정보가 필요할 때

지금은 서버가 없어서 **화면 시연용 로그인**만 구현함.
회원가입 진행시, 이름·학번이 브라우저에 저장되고(비밀번호는 저장 안 함) 모든 페이지 상단바에 똑같이 표시되는 상태

본인 페이지에서 로그인한 사용자 정보가 필요하면

```js
const user = SCH.getUser();   // 로그인 안 했으면 null
// user = { username, name, studentId, department, semester }

// 로그인·로그아웃할 때마다 실행할 코드
document.addEventListener('sch:auth', (e) => {
    const user = e.detail;    // 로그아웃이면 null
});
```

와 같이 구현

-> 나중에 Flask에서는 서버 세션(`session['user_id']`)으로 바뀔 예정, 위 공통 틀은 `base.html` 하나로 합치면 깔끔할 것 같음!
